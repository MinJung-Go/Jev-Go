中断错误是适配器报告的“未返回有效候选坐标 JSON”，可能涉及格式、字段或候选合法性；记录未保留失败的上游原文，不能进一步认定具体原因。耗时统计包含中断局中已成功的调用，不含失败请求。

重复空盘与相同提示词可能产生重复棋谱，不能当作20种独立开局。完成局又受到中断筛选影响，不据此推断总体棋力胜率。结果属于模型与规则辅助的组合，不能分离安全对齐或长尾能力。

所有已落子状态逐手重放核对，终局额外用独立四方向扫描检查连五；错误局没有强行补走。plan.json 的代码提交指向未改动的demo实现，runner.py保存本轮实际使用的批量脚本。旧两局不混入本批次。
